# LLM 学习知识卡片（P2 RAG 的检索语料）

> 每张卡片是一个独立知识块（检索的最小单位），内容取自本仓库 T1-T5/P1 的学习主题。

## KB-01
反向传播是链式法则在计算图上的遍历：前向建图（DAG），反向按拓扑逆序把梯度从输出累加回每个参数。一个节点被多条路径引用时梯度用加法累积，这就是 grad 用 += 而不是 = 的原因。

## KB-02
学习率调度通常用 warmup 加余弦衰减：初始阶段线性升温，让 Adam 优化器的动量估计稳定下来；之后余弦衰减到峰值的 10%，小数据集上防止后期过拟合。梯度裁剪按全局范数截断到 1.0，防异常 batch 把参数打飞。

## KB-03
BPE 分词器把文本当字节流处理：初始词表是 256 个字节，反复合并最高频的相邻对生成新 token。字节级保证任何 UTF-8 文本（中文、emoji）都不会出现未知符号。词表大小直接决定 embedding 矩阵的行数。

## KB-04
GPT-2 使用预归一化（Pre-LN）残差结构：子层先过 LayerNorm 再进 attention 或 FFN，梯度经残差主干直通各层，深层训练稳定。原论文的 Post-LN 需要 warmup 才训得动。

## KB-05
注意力机制中 Query、Key、Value 三者分工：Query 是当前 token 的查询向量，Key 是各位置的索引标签，Value 是实际信息。权重等于 softmax(QK^T/sqrt(d))，除以 sqrt(d) 是防止点积方差随维度放大导致 softmax 饱和。

## KB-06
多头注意力把嵌入维度切成多个子空间并行做注意力再拼接，每个头可以学习不同的关注模式，例如指代消解、邻近修饰、句法依赖。

## KB-07
因果掩码保证位置 t 只能看到不超过 t 的位置：把注意力分数的上三角填负无穷，softmax 后未来位置权重恰好为零。这使语言模型可以并行训练（teacher forcing）又不会泄漏未来信息。

## KB-08
温度参数控制采样的随机性：logits 除以温度，温度趋近 0 近似贪心解码（稳定但重复），温度高则多样但容易混乱。top-k 采样只保留概率前 k 的候选再归一化，截掉长尾低质量 token。

## KB-09
语言模型的评价指标是平均负对数似然（NLL），等价于交叉熵。困惑度 perplexity 是 NLL 的指数，含义是模型在每个位置把不确定性压缩到几选一。字符级模型在莎士比亚语料上训到困惑度 5 左右即具备可读生成。

## KB-10
bigram 语言模型直接统计相邻字符对的频率，没有可学习参数，上下文只有 1 个字符；MLP 语言模型（Bengio 2003）引入字符嵌入，把上下文扩展到 3 个字符，泛化能力来自嵌入空间中相似字符共享经验。

## KB-11
预训练中的过拟合现象：训练 loss 持续下降而验证 loss 回升，说明模型开始背诵训练集。小语料上每个 token 被重复看几十遍必然过拟合，真实大模型预训练让每个 token 只被看一两遍（Chinchilla 配比原则）。

## KB-12
GPT 的参数量速算：不含嵌入时每层 12 乘以 d 的平方（attention 占 4d²，FFN 占 8d²），加词嵌入 vocab 乘 d 与位置嵌入 ctx 乘 d。GPT-2 124M 可由此验算。

## KB-13
Transformer 前馈层（FFN）是先扩展 4 倍再收缩的两层 MLP，中间用 GELU 激活。每个位置独立变换，参数占每块的三分之二，与 attention 的「通信窄、计算宽」分工。

## KB-14
权重共享（weight tying）：GPT-2 的输出投影与输入嵌入用同一矩阵，节省 vocab 乘 d 的参数量，小模型上训练更稳定。但要注意训练目标必须左移一位（位置 t 预测 t+1），否则会出现输出恒等于当前输入嵌入的捷径。

## KB-15
模型初始化用 normal(0, 0.02) 而非默认的 N(0,1)：默认初始化的 logits 方差随嵌入维度放大，初始 loss 可达 38 而非均匀基线。残差分支的输出投影额外乘 1/sqrt(2 倍层数)，补偿深层堆叠的方差增长。

## KB-16
RAG 检索增强生成分三步：把文档切块并 embedding 入库；用户问题同样 embedding 后做向量近邻检索取 top-k；把检索到的块拼进 prompt 交给大模型生成答案。优点是知识可更新、可溯源，不必重训模型。

## KB-17
文本切块（chunking）的常用策略：按语义边界（段落/标题）优先切，块太长则按固定长度滑窗切并保留重叠（overlap），重叠保证跨块边界的句子不至于两头都丢上下文。

## KB-18
TF-IDF 是最经典的稀疏 embedding：词权重等于词频乘逆文档频率（idf），出现越普遍的词权重越低。L2 归一化后向量内积即余弦相似度。中文无空格分词，常用字符 bigram 代替。

## KB-19
hit-rate 是检索评测指标：如果期望的文档出现在 top-k 检索结果里记为命中。hit@1 要求第一名命中，hit@3 允许前三名。评测集应覆盖多种问法（同义改写）来检验鲁棒性。

## KB-20
API 客户端的重试要区分错误类型：429 限流和 5xx 服务端错误值得指数退避后重试；401 鉴权失败和 400 参数错误重试不会成功，应立即失败，避免浪费配额。

## KB-21
让模型稳定输出 JSON 的两层防御：请求带 response_format 为 json_object 让服务端约束输出；客户端解析失败时把错误输出拼回对话，要求模型自我修正后再试一次。

## KB-22
prompt 对照实验的方法论是控制变量：一次只改一个维度（长度约束、结构约束、角色设定），固定其他条件对比输出，否则效果提升无法归因。每次实验记录回复内容与延迟。

## KB-23
MPS 是 PyTorch 在 Apple Silicon 上的 GPU 后端（Metal Performance Shaders），实测同配置训练比纯 CPU 快约 15 倍。MLX 是 Apple 官方的原生机器学习框架，API 独立于 PyTorch，微调场景常用。

## KB-24
知识库问答的生成环节：把检索到的 top-k 块编号拼进 system prompt，要求模型只依据给定资料回答并标注引用编号，检索不到相关内容时明确说不知道，抑制幻觉。
