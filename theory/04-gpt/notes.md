# T4 讲解笔记：Attention 与 GPT

## 问题

- Attention 到底在算什么？为什么除以 √d？为什么不能看未来？
- 一个能训练的 GPT 除了 attention 还需要哪些部件？

## 1. Attention：可微分的「按相关性查表」

每个 token 生成三个向量：

| 向量 | 含义 | 比喻 |
|---|---|---|
| Query (Q) | 我想找什么 | 检索词 |
| Key (K) | 我能提供什么 | 索引标签 |
| Value (V) | 我实际携带的信息 | 文档内容 |

`注意力权重 = softmax(QKᵀ/√d)`，输出 = 权重对 V 的加权平均。整个过程可微分，
因此「该关注谁」可以被梯度下降学出来——这是与硬性检索的本质区别。

**为什么除以 √d**：Q、K 各维独立同分布时，点积方差 ∝ d。d=64 时点积量级 ~8，
softmax 进入饱和区（近似 one-hot），梯度接近 0。除以 √d 把方差拉回 1。

**因果 mask**：位置 t 只允许看 ≤t 的位置。实现上把上三角填 `-inf`，softmax 后
权重恰为 0。等价于官方 SDPA 的 `is_causal=True`（本章测试做了数值对齐，误差 <1e-5）。
因果性的一个免费测试：**篡改未来位置的输入，过去位置的输出必须纹丝不动**（测试里有）。

**多头**：把 emb_dim 切成 n_head 份，每份独立做注意力再拼接投影——
相当于在多个子空间并行学习不同的「关注模式」（如指代、邻近、句法）。

## 2. GPT 完整拼装

```
x = tok_emb(idx) + pos_emb(pos)          # 内容 + 位置信息
for block in blocks:                      # ×n_layer
    x = x + attn(ln1(x))                  # 子层一：通信（token 间交换信息）
    x = x + ffn(ln2(x))                   # 子层二：计算（每位置独立非线性变换）
x = ln_f(x); logits = head(x)             # head 与 tok_emb 共享权重（GPT-2）
```

两个结构选择的理由：

- **Pre-LN（先归一再进子层）**：梯度经残差主干直通各层，深层训练稳定；
  Post-LN（原 Transformer 论文）需要 warmup 才训得动。GPT-2 起全部 Pre-LN。
- **FFN 是 4 倍扩展**：`C→4C→C`，参数占每块 2/3（8d² vs attention 的 4d²）——
  「通信窄、计算宽」是 Transformer 块的分工。

**参数量速算**（不含嵌入）：每块 12·d²（attention 4d² + FFN 8d²），
加词嵌入 vocab·d（权重共享所以只算一次）+ 位置嵌入 ctx·d。
验算 GPT-2 124M：12 层 × 12 × 768² = 84.9M + 50257×768 = 38.6M + 1024×768 ≈ 0.8M → **124M** ✓

## 3. 本章踩的两个真实的坑（都在测试里回归固化）

### 坑 1：权重共享 + 未移位 target = 恒等捷径

把 `targets=idx`（位置 t 预测位置 t 的同一个 token）传进去，**未训练的模型 loss ≈ 0**。
原因：残差流里本来就含 `tok_emb[idx_t]`，而输出头就是同一矩阵——
`logits[t][idx_t] = ‖emb‖²/规范化` 天然远大于其他类。正确约定是 **位置 t 预测 t+1**
（`x=idx[:,:-1], y=idx[:,1:]`），因果 mask 保证 t 看不到 t+1，捷径被封死。

### 坑 2：默认初始化的初始 loss 高达 38

PyTorch 默认 Embedding/Linear 初始化是 N(0,1) 量级，logits 方差随 emb_dim 放大
（C=64 时 logits 标准差 ~8），初始 cross-entropy ≈ 38 而非均匀基线 ln(vocab)=1.6。
GPT-2 的工程解法（本章已实现）：

- 全部权重 normal(0, **0.02**)；
- 两条残差路径的**输出投影**再乘 1/√(2·n_layer)——每块给残差流加两次方差，
  预先缩小补偿，防止深层方差线性爆炸。

初始化不是玄学，是把「起点」放在损失面友好区域的最便宜的手术。

## 4. 采样：temperature 与 top-k

- **temperature**：logits 除以 T。T→0 近似贪心（稳定但重复），T 大则多样但易乱。
- **top-k**：只保留概率前 k 的候选再归一化，截掉长尾低质 token。
- 自回归生成 = 循环「前向 → 取最后位置分布 → 采样 → 拼回输入」，序列超 block_size 时截尾。

demo 实测：随机初始化的模型采样是字符噪声；同一模型在一段英文上训 300 步后，
低温采样即能复现训练文本的短语结构（见章 README）。
