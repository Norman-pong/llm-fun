# T1 学习笔记：autograd 与反向传播

## 问题

- 反向传播到底是什么？为什么一次后向遍历就能算出所有参数的梯度？
- 计算图、拓扑序、链式法则三者怎么串起来？

## 核心推导

### 1. 反向传播 = 计算图上的链式法则

任何标量表达式都能拆成 DAG：叶子是变量/参数，内部节点是算子。
求 dL/dx 时不需要对每个参数单独求导，而是从 L 出发**一次遍历**把梯度"流"回每个节点：

链式法则的多元形式（x 被 y₁, y₂ 两条路径使用时）：

```
dL/dx = Σₖ (dyₖ/dx) · (dL/dyₖ)
```

这就是代码里 grad 用 `+=` 而不是 `=` 的原因——一个节点可能被多条路径引用（菱形依赖），
每条路径的梯度贡献要**累加**。micrograd 的 `a*b + a*c` 就是最小例子。

### 2. 每个算子只需知道自己的局部导数

| 算子 | 前向 | 局部导数（传给输入的梯度） |
|---|---|---|
| `a + b` | a+b | 各得 `1·out.grad` |
| `a * b` | a·b | a 得 `b·out.grad`，b 得 `a·out.grad` |
| `x ** k`（常数 k） | xᵏ | `k·x^(k-1)·out.grad` |
| `-x` / `a-b` | -x / a-b | 归约为乘法/加法组合 |
| `a / b` | a·b⁻¹ | 复用 mul + pow(-1) |
| `relu(x)` | max(x,0) | `x>0 ? out.grad : 0`（x=0 处取 0，与 PyTorch 一致） |
| `tanh(x)` | tanh(x) | `(1-t²)·out.grad`，t 为前向值 |
| `exp(x)` | eˣ | `eˣ·out.grad`（导数是自己） |

关键认知：**框架的"魔法"只是把这张表 + 拓扑排序 + 累加规则工程化**。
PyTorch 的 `Tensor.backward()` 与本引擎的 `Value.backward()` 做的事完全同构。

### 3. 为什么必须拓扑排序

`node._backward()` 会读取 `out.grad`，只有当 node 的**所有下游**都反传完毕后才能调用。
DFS 后序恰好给出拓扑序，`reversed()` 后从输出往输入逐个触发——
这就是"前向建图、反向按逆拓扑序释放梯度"的全部机制。

### 4. 实现结构（engine.py）

```
Value: data(前向值) + grad(累计梯度) + _prev(输入节点) + _backward(闭包: 局部导数怎么分回去)
backward(): self.grad=1 → 拓扑排序 → 逆序逐节点调用 _backward()
Neuron/Layer/MLP: 纯 Value 组合出的 tanh 激活 MLP，零框架依赖
```

`_backward` 用闭包捕获前向值（如 tanh 的 t），避免反传时重算——这就是 PyTorch
"前向保存中间量给反向用"的雏形（如 tanh 保存输出、mul 保存对方输入）。

## 实验记录

### 梯度对齐（test_engine.py，DoD 1）

- 12 个随机复合函数（3 变量、8 层随机算子叠加的 AST），同一棵树分别交给
  手写引擎（Python float64 标量）和 torch（float32 张量）求值、反向。
- **全部对齐，最大误差 < 1e-5（atol 阈值）**；13 个单算子用例（含 div/pow(0.5)/r 系操作）同样全过。
- 有意让复合函数避开 exp 连锁与 pow 连锁（float32 下溢出/大数会放大舍入差），
  保持梯度量级 O(1)，验证的是"求导机制正确"而非"浮点极限"。

### MLP 训练（mlp_demo.py，DoD 2）

- 任务：24 个二维点的 XOR 分类（y = sign(x1·x2)，线性不可分）。
- 模型：MLP [2, 8, 1]，隐层 tanh、输出线性；MSE loss；全批 GD，lr=0.08，250 epochs，固定种子。
- 结果：**loss 从 1.1332 单调降至 0.1644（每步均不上升），准确率 96%**。
- 单调性来源：全批梯度 + 足够小的 lr，梯度下降在局部单调收敛；若改 SGD 小批会有噪声抖动。

## 踩坑

- **torch 对"未参与输出图的叶子"梯度是 None**（不是 0），对齐测试要先把 None 归一为 0 再比较；本引擎记 0.0，语义更直观。
- relu 在 x=0 的次梯度取 0（和 PyTorch 默认一致），否则对齐测试会在边界值翻车。
- float32 的 torch 与 float64 的 Python 标量比较要控制表达式量级：误差 ~ 量级×1e-6，
  保持梯度 O(1) 才能稳过 atol=1e-5。

## 心得 / 还想深入

- 反向传播拆开看就是三件事：**建图（DAG）、排序（拓扑）、累加（链式法则）**，没有魔法。
- `__radd__/__rmul__/__rsub__` 这些反射方法是让 `2.0 - a` 这类混合运算自然落进 Value 体系的关键，写 DSL 时很实用。
- vector-Jacobian 积累（vjp）是标量版 `out.grad` 的推广；T4 手写 attention 反传时用的正是矩阵版链式法则。
