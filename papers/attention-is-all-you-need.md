# 论文精读：Attention Is All You Need

> Vaswani et al., NeurIPS 2017。绑定章节：T4（theory/04-gpt）。

## 一句话贡献

抛弃 RNN/CNN 的序列归纳偏置，纯用注意力做序列建模——Transformer 架构的出生证明，也是现代所有 LLM 的骨架。

## 核心公式（只有一行）

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

每个位置用自己的 Query 去匹配所有位置的 Key，相似度归一化为权重后加权聚合 Value。信息流动由数据（学出来的 QKV 投影）决定，而非结构（RNN 的时序链）决定。

## 值得注意的设计决策（按重要性）

1. **√d_k 缩放**：点积方差随维度线性增长，不缩放则 softmax 饱和、梯度消失。论文 3.2.1 节专门论证（T4 的 attend 实现与此一致）。
2. **多头**：8 个头并行，每头 d_model/8 维。论文的消融显示头数太多/太少都变差——子空间切分有最优粒度。
3. **位置编码用固定正弦**：注意力本身是置换不变的，必须注入位置信息。后续演化：可学习（GPT-2，T4 实现）→ 相对位置偏差（本仓库未实现）→ RoPE（Llama，backlog T6）。
4. **Post-LN + 残差**：原论文子层后归一化。**这是后来被证伪的决策**——GPT-2 起 Pre-LN 成为主流（深层训练稳定，见 T4 实现），本文的 Post-LN 需要 warmup 才训得动。
5. **FFN 4 倍扩展**（d_model→d_ff=4·d_model）：参数大头，位置独立计算。这个比例沿用至今。

## 与本仓库实现的对照

| 论文 | T4 gpt.py | 差异原因 |
|---|---|---|
| Post-LN | Pre-LN | 2018 后共识：深层稳定优先 |
| 编码器+解码器+交叉注意力 | 仅解码器（因果 mask） | GPT 路线：自回归生成不需要编码器 |
| 固定正弦位置编码 | 可学习位置嵌入 | GPT-2 选择 |
| 标签平滑 ε=0.1 / beam search | 交叉熵 + 采样 | LM 目标不同 |

## 实验证据（论文）

WMT14 英德 BLEU 28.4（超当时所有单模型与集成），训练成本远低（12 小时 8×P100 量级）。注意力可视化显示头分工：有的头做句法依存，有的做指代对齐。

## 批判性视角

- 自注意力的 O(T²) 复杂度在本文就已被指出；长上下文的后续演化（稀疏/线性注意力/FlashAttention 的 IO 优化）都在还这笔债。
- 「Attention is all you need」标题党了：FFN 占 2/3 参数，残差和 LayerNorm 同样不可或缺——去掉任何一个都训不动。
